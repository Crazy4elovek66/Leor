# SECURITY_CHECKLIST.md

Перед каждым коммитом агент обязан проверить следующее.

## Секреты

Проверить, что не закоммичены:

- `.env`
- `.env.local`
- токены
- ключи
- credentials
- JSON-ключи сервисов

## Логи

Удалить:

- `console.log`
- `debug`
- временные принты

## Ошибки

Проверить:

- обработку ошибок;
- пустые состояния;
- loading состояния;
- retry.

## Типы

Не должно быть:

- `any`
- `@ts-ignore`
- необоснованных type assertions

## Производительность

Проверить:

- лишние ререндеры;
- бесконечные эффекты;
- дублирующиеся запросы.

## Безопасность

Проверить:

- XSS;
- небезопасный HTML;
- открытые redirect;
- доверие данным Telegram.

## UI

Проверить:

- мобильную адаптацию;
- темную тему;
- длинные русские строки;
- доступность.

## Запрещенные действия

Никогда не:

- коммитить секреты;
- удалять миграции;
- переписывать историю main;
- делать `push --force` без разрешения;
- отключать проверки безопасности;
- хранить пароли в коде;
- хранить токены в `localStorage`;
- отключать HTTPS;
- использовать `eval`;
- использовать `dangerouslySetInnerHTML` без строгой необходимости.
